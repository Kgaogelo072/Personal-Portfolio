# Kgaogelo Tshabalala – Portfolio

Personal portfolio of Kgaogelo Tshabalala, a Johannesburg-based full-stack developer (C#/.NET, Angular, SQL Server, Azure).

**Live site:** https://kgaogelotshabalalaportfolio.netlify.app

## Stack

React 18, React Router, Vite, deployed on Netlify.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
